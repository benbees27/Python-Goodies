# Python Goodies

Small Python scripts and toys.

| Script | What it does |
|---|---|
| `Hello.py` | Greets you if you type "Hello" |
| `Text Maker` | Turns text into colored ASCII art (pyfiglet + colorama) |
| `Animated Rainbow` | Animated rainbow ASCII text (pyfiglet + rich) |
| `Ant V1` / `V2` / `V3` | Ant-colony simulations in pygame (V3 is the latest) |

```
pip install pyfiglet colorama rich pygame
python "Python Goodies/Text Maker"
```
(The files without extensions are Python; run them with `python <file>`.)
